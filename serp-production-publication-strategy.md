### Snippet Optimization Rules
1. **Paragraph snippets**: Answer in first 40-50 words, then expand
2. **Table snippets**: Use clean HTML `<table>` with clear headers
3. **Place snippet-bait directly under the matching H2** — Google pulls from the first content under the heading
4. **Include the question in the H2** — "How much tax do I pay on $80,000?" as H2

### AI Overview Targeting

AI Overviews appear for many calculator queries. To be cited in AI Overviews:
1. **Provide clear, factual answers** with specific numbers (not vague)
2. **Use structured data** — FAQPage + WebApplication schemas
3. **Include worked examples** — AI Overviews pull from pages with concrete calculations
4. **Source your data** — "According to the ATO..." builds citation credibility

# Part 2: Production Management (Skill 29)

## Quality Assurance Checklist — Pre-Publication

### Content Quality (Per Page)
- [ ] All numbers match EAV Knowledge Base
- [ ] Financial year specified (FY2025-26) on every page with figures
- [ ] Source attribution present (ATO, FWC, NES)
- [ ] Word count meets brief target
- [ ] Brand voice audit: Grade 8-10, formality 4/9, "you" perspective
- [ ] No forbidden words (guarantee, hack, guru, leverage, seamlessly, utilize)
- [ ] Power words present (accurate, free, instant, calculate, breakdown)

### SEO Quality (Per Page)
- [ ] Title tag matches brief (under 60 chars)
- [ ] Meta description matches brief (under 155 chars)
- [ ] H1 contains primary keyword
- [ ] H2 structure matches content brief
- [ ] Primary keyword in first 100 words
- [ ] All internal links from linking architecture implemented
- [ ] Anchor text matches specification
- [ ] No broken links
- [ ] Images have alt text with relevant keywords

### Technical Quality (Per Page)
- [ ] Schema markup validated (Google Rich Results Test — no errors)
- [ ] Page loads under 2 seconds (mobile)
- [ ] Mobile responsive — calculator works on 320px screen
- [ ] Open Graph tags set (title, description, image)
- [ ] Canonical URL set
- [ ] BreadcrumbList schema present
- [ ] `dateModified` auto-updates on content changes
- [ ] No duplicate content / unique across site

### Calculator Functionality (Calculator Pages Only)
- [ ] Calculator produces correct results at $50K, $80K, $100K, $150K, $200K
- [ ] Results match EAV worked examples table
- [ ] All pay frequencies display correctly (weekly/fortnightly/monthly/annual)
- [ ] HECS toggle works correctly
- [ ] Edge cases handled (zero input, very high salary, decimal input)
- [ ] "Copy results" button works
- [ ] Calculator is accessible (keyboard navigation, screen reader labels)
